Hospital San Diego EnergyPlus starter package

SOURCE
1) IDF and annual HTML: PNNL ASHRAE 90.1-2019 Hospital prototype, SanDiego variant, EnergyPlus v22.1.0
2) EPW: San Diego - Brown Field Muni AP, station 722904, TMY3 (8760 hours)

CONTENTS
Hospital_SanDiego.idf : unchanged source IDF
SanDiego_BrownField_TMY3.epw : original uploaded weather file, with .epw extension
Hospital_SanDiego_annual_summary.html : original PNNL annual summary

TO RUN
Install EnergyPlus 22.1.0. Run the IDF using the EPW file.
CLI example: energyplus -w SanDiego_BrownField_TMY3.epw -d results Hospital_SanDiego.idf
The existing IDF has limited hourly outputs. Add Output:Meter/Output:Variable
requests AFTER checking output dictionaries generated by EnergyPlus.

MODEL CAVEATS
PNNL Hospital is a reference building, not NMCSD. The equipment plant from NMCSD must
be built separately, with consistent energy-service demand interfaces.
The source IDF already has chillers/boilers; do not directly treat its total electricity
consumption as exogenous demand while modeling a replacement central plant (double-counting).
Any proposed fault statistics or clinical demand shocks require separate evidence/assumptions.
The supplied NMCSD PDF distinguishes existing and prospective equipment.
