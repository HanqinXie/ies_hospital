# V26 假设、定义与适用范围

本表补充并保留 V25 假设；没有修改原容量、负荷等级、故障定义、保护阈值、能源价格口径或服务恢复判据。当前研究入口转发真实 `M25_model_correction` 物理实现，另记 V26 study ID；不把命名升级当成物理修复。

| 项目 | 本轮处理及限制 |
|---|---|
| 原始输入 | 保留原 DOE/IDF/8760 输入；28项输入逐字节复核。未推断 OEM 额定值、并网权限或医院临床安全保证。 |
| 冷水库存 | 使用原 SQL 的三个 PlantLoop 模型自动估算水体积，每环 5.179641956509636 m³，不是医院实测管网容积。按版本源码 InitConvTemp=5.05°C 的水密度换算模型固定质量，各半环约2589.56 kg；没有增加水量或人为设为全环7.22°C。 |
| 冷水温度 | Native lumped-capacitance temperature 是解析区间均温；真正始末温度由同版本状态方程反演，明确标为重建量。原生 Heat Storage Rate 为独立主账项，不用末减均温冒充库存变化。 |
| 有符号换热 | 保留盘管反向放热、双侧 HX 内部抵消、泵向水放热与冷机蒸发器抽热。零流量时陈旧节点温差不算换热；Plant Cooling Demand 不填平残差。 |
| 冷侧准入误差 | 正常参考后、受限工况前固定：速率10 W，积分绝对值与绝对残差积分均不超过10 W×时长；节点温差0.01°C、质量流量差0.001 kg/s，零流 HX 原生热率1e-6 W。它们是源常数支持的研究准入门槛，不是EnergyPlus保证所有水环都逐点达到的合同。未为正常残差放宽。相对残差分母为所有边界交换绝对量之和，下限1 kWh。 |
| 水力解释 | 原模型无压力求解的植物环路流量请求，不能证明停泵后实际存在水力驱动。保留原模型状态并明确限制；没有把二次泵宣称为主环驱动，也没有强迫流量归零来制造闭合。 |
| 空气与房间 | AHU焓差、盘管总/显冷、风机热、末端再热、房间系统显热属于不同边界。新风/排风与当前房间焓基准单列；回风节点与当前房间状态之差保留未解析部分，不冒认为额外冷源。 |
| 倍率 | 区域与物理组倍率按实际变量定义一次换算；OR2组的System显热已含倍率，不能再乘5。H−C另按其变量定义处理。各字段定义、时钟、单位保留在注册表与源代码分析。 |
| 真实空气历史 | EnergyPlus空气方程使用原三阶历史；一次差分的报告均温不是该方程的导数。隐藏AirPowerCap与回滚/试算历史不能被事后参数代理称为实测真值。 |
| 温度结构 | 最多两个结构：纠正绝对背景与空气历史的原三热体，以及同三热体加无热容的代数表面接口。空气、家具/内部质量、建筑材料库存不重叠，没有第四热体。每区域同一参数覆盖2h和6h事件。 |
| 温度参数与边界 | 四参数Cf/Cc/G/家具分配比，材料容量上界不超过原IDF实际库存；仅两个固定初值，每结构4区，共16次优化器调用，各max_nfev=200。初始内部材料均温以首个当前表面观测代表，是公开的均匀体假设，不是拟合初值。 |
| 表面与天气简化 | 内面采用材料半层热阻、辐射吸收与TARP对流；外面用真实外表面积、McAdams 5.8+3.8v、简化无遮挡太阳/天空/地面辐射。地面反射率0.2、地面辐射温度近似室外温度、均匀站点风速，均为研究简化，不称为原EP外表面/CTF的等价实现。OR4无外立面，外路径为零。 |
| 信息界限 | 离线辨识可以使用已完成的原生观测；这不等于控制器在线可读取未来墙温/故障结束/正常参考。候选使用已完成小时的天气保持，不插值未来小时；自身≤1min因果验证是独立门槛，未执行时明确未执行。 |
| 温度评价 | 主表为绝对室温误差，同时保留模型实际−模型正常的成对扰动误差。共同偏差不得靠相减隐藏。事件RMSE≤1°C、恢复首6h≤0.5°C、最大误差≤2°C、首次越界误差≤10min、原连续三点恢复时间误差≤20min。未恢复保留null/删失，不填0。原8夏季适用门槛全部通过后才允许新日期验证。 |
| 复合事件 | 先按正常实际运行路径选择GT2；四例固定同h4001、180min、H0、850kW电网、response_delay=30min与同初始库存/已到达许可及队列。它限定事件30–60min响应受限，不代表每条命令队列延迟30min。事件30–90min；D为ER四区域电/热/冷请求增加25%。事件后观测/执行自然分化，接口和权限规则保持一致。不是单台锅炉组的虚构额定分摊。 |
| 费用与排放 | 费用沿用原USD2001口径，不作现行电价。CO₂是原研究排放因子下的条件计算，不能视为全生命周期结论。服务无工程中断不等于原始每步ENS严格为零；保留极小数值边界。 |
| 版本与历史 | C物理运行绑定Source01；A正常观察保留原Source01，其余7例绑定A Component02；混合时间戳解析修复只改变分析适配，并有等值证据。B拟合绑定独立84项输入/源码及预登记SHA。不会把早期记录改标为最终源码。 |
| 默认耦合 | 冷侧、温度和端到端门槛共同通过才可试验耦合；否则默认thermal_coupling=None。室温表观正常不能抵扣冷ENS。 |
| 观察器健壮性 | 独立审阅指出，观察资格的差值比较尚未统一显式拒绝NaN，以及trace.finish异常时可能先退出再落盘详细CSV。本轮实际记录未触发，原生边界分析另有finite检查，所有限定诊断均有终端回执；这些是后续新观测前应补强的健壮性限制，不能把当前观察器宣称为任意异常下都能保全详细原始CSV的通用接口。当前冷侧资格仍false。 |
| 存储与归档 | 大文件保留在D/E本机。包内保留可直接重放的原生CSV、轨迹、资格、日志、失败/未知和必要SQL；重复SQL/ESO/HTML、完整求解矩阵等只省重复或深入复核层，逐件保留真实路径/字节/SHA/原因。未删除原件。 |

全部阶段的真实命令、退出码和日志见 `verification/steps/` 及各组件回执。拟合收敛、API输出匹配、方程恒等式与物理/温度准入分别报告，不能互相代替。
