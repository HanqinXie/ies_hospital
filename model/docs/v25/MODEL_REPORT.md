# 医院 IES V25 模型修正与运行用途对照

22个最终代表工况已完整完成；本报告区分模型行为回归、运行规则取舍与尚未通过的温度/接口资格，不把完成轨迹或测试通过当作医院服务安全认证。

## 供能过程真正改变了什么

本轮修正了有限DG能源下的返网准备时机，并把“短时接续/当前服务”与“持续关键保障”分成两个可追溯的运行选项。物理容量、连接、许可、启动/切换时长、P0–P3分类与评价判据均沿用V24。持续保障选项改变运行目标的先后次序，不是新增硬件或守恒修复；温度输出口径虽已修正，温度模型和完整在线热端口仍未准入。

关键区建筑电需求已经含原分配风机、水泵电耗，不重复加电。冷量到达区域仍须有风机与水泵路径；蓄冷专用泵另付实际电耗。锅炉辅机、付电复归、GT启动等厂站支路需要真实nonUPS源，建筑UPS不能代供这些支路。DG按有限轴功库存结算，不能把轴功预算直接当电交付量；“已发命令/控制可用/许可上限/库存充足”均不能代替实际供能证明。
