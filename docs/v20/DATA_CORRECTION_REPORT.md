## 3. 代表时段及非单调热变化

以下均是原输入同一小时，写作“V19→V20 kW”；不是事故或策略输出。2017时间戳仍是既有日历标签，不表示实测气象年。

P0/P1电与P1热在全部8760小时下降，但**P0热在4695小时上升、4065小时下降**。P0热最大增加13.234814 kW、最大减少50.326427 kW；全年略降不能写成每时刻都降。原因是旧重复倍率令尤其P1的热代理过大，再对三个等级统一压缩；去掉重复数后解除这个缩放，部分P0时刻反而恢复更高需求。小时33就是P0热增加的真实例子。P3电与热在全部8760小时增加。

因此，新口径既减少了部分被高估的关键电/热请求，也可能令部分时刻P0热保障更难。设备出力、替代、启动、缺供、预算耗尽和策略比较应按新需求实跑，不能由算术差额直接推出保障改善。

`grouping_diagnostics(zone_df,hourly)` 逐小时、逐e/h/c保留P0–P2原代理、代理和、建筑总量、压缩比例、超出量、是否压缩与P3余量，合同为 `hospital_ies.load_accounting.v20.v1`。完整28列、8760行见 [V20分组诊断CSV](../../outputs/v20_load_accounting_20261019_run01/provenance/load_grouping/annual_audit01/V20_GROUPING_DIAGNOSTICS.csv)；[压缩前后原始审计CSV](../../outputs/v20_load_accounting_20261019_run01/provenance/load_grouping/annual_audit01/PRECOMPRESSION_BY_HOUR_CARRIER.csv)保留全部小时而非只保存异常小时。最大守恒残差2.27×10⁻¹³ kW。

代表单区温度仍使用原单区显热冷量、C与UA；实际倍率1/4/5/6电表案例和重复区域数改变的温升不变性由新增回归分别检验。保留原热容量和温度代理不等于其已现场校准；温度未越限也不抵销实际缺冷。
