# V19 假设与适用边界登记

本表记录本轮新增或明确化的研究假设。原始 DOE/IDF/8760 数据、容量、物理连接、保护阈值、失效判据与 P0–P3 服务锁没有因本轮修复而调整。现场/OEM/临床证明缺失不能用求解成功代替。

| 编号 | 本轮处理 | 来源、范围与限制 |
|---|---|---|
| A19-01 | 需求、主动断开、已连接少供、实际交付分开 | 十二个普通接点坐标独立于当期 unmet；关键主动 cut 在原关键服务锁后优先最小。保持请求不产生能量。普通命令明确隔离及真实自动安全切除仍有效。未新增任意关键切除的安全许可或硬接线证明。 |
| A19-02 | 电网回切最多等待 30 min | 研究控制时钟，不是厂家切换保证。只用已观察健康电网/持久许可、当前 DG 支撑和当前实际 GT 端口检查；DG 不再能支撑或等候届满时，可接受有限 OPEN 间断。保留原 PREPARE=0.25 min、OPEN=0.25 min 及 GRID/DG 不并联。 |
| A19-03 | 当前桥接检查与条件 GT 目标分开 | 静态端口证明只覆盖当下聚合能量平衡，不保证未来需求或连续机械过程。`grid_open_target` 只在已观察的回切等待中请求合法普通 GT 目标，不给 R=30 min 就绪信用或完成时刻保证；未就绪 GT 不进入实际 OPEN 供给。 |
| A19-04 | 两种 C 策略仅作有限能源取舍 | C18/M19 兼容版包括共同接点语义与回切信号适配；C19 上移关键条件准备并添加预留偏好。H 根据当前 P0/P1 直接电、按现有 EC 转换率计算的冷辅机参考、剩余轴功和已登记损耗计算，最少沿用一小时支持长度；没有在线停电终点。H 为偏好，不是物理保证，可能减少 P2/P3 服务。 |
| A19-05 | 接点 0/0.25 min 及 OPEN 0.25/1 min 对照 | 延续原敏感性，不添加虚拟负荷、免费外送、储能或延后保护。零接点延迟是聚合准稳态假设。正延迟的实际余留损失须在结果正文并列，不能声称对所有有限机械执行时间稳健。 |
| A19-06 | 本地数值收尾 | 原验证门槛保留：原域物理/边界 1e−7、优先锁 1e−10、整数 1e−9。已见数值失败可在原层剩余预算内额外一次原域 Method 0 暖启动优化；须真实优化证书、目标/dual gap 和原后验校验，不能退前向量冒充新最优。数值最优不等于精确数学或现场保证。 |
| A19-07 | 天然气 HHV 账 | 原模型 MMBtu 未明确 HHV/LHV；为事后评价明确按 HHV 解释并配 EPA 同口径因子。若原能量价格/热值另有口径，须重算该项。CO2 没有进入调度目标。 |
| A19-08 | CAMX 电网因子 | 气象输入对应 Brown Field、加州。主评价采用 EPA eGRID2023 Revision 2 CAMX 年度因子；这是地区/年份明确的情景账，不是合成 2017 时间戳或真实医院逐时盘查。另保留登记的因子版本敏感性。 |
| A19-09 | DG 化学燃料为条件估计 | 轴功预算是 shaft-equivalent kWh，不是柴油升数或化学热。采用官方代表机组轴功—油耗点给固定 s(L/kWh_shaft) 情景；本机标定、低负载、启动和空转曲线未知。轴功扣账已包括启动、损耗和转子储能变化，不重复加一次。分开报告 grid+gas 已知小计、条件 DG/总量及 exact-DG unknown。 |
| A19-10 | 确认数据的有限支持 | 原80已见，只作回归；原最终12继续封存。新小确认须在完整源码/参数/评价冻结后，排除历史训练和本轮全部注册/失败/未知支持与两侧隔离带再选择。只支持同一合成年份/医院模型的案例比较，不是新医院或事故概率验证。 |
| A19-11 | 机器耗时与模拟时钟分开 | 求解、积分和序列化的实测墙钟用于资源记录，不另行加到模拟命令到达时间。单步计时包含相应执行路径，不能当作纯规划延迟；未提供现场在线实时性证明。未改变原决策步长或命令时钟。 |

原研究简化仍保留：共享冷却塔、简化电热冷枢纽、缺少真实配电潮流和 OEM 继电保护数据、低阶未校准温度代理、示例成本和有限 DG 轴功预算。温度未越限不抵销实质缺冷；健康设备失去上游能源不等于设备硬件发生继发故障；L2 标签不等于实际发生了继发跳机。

四个正常窗口只作连续运行与同窗口费用/排放比较，不外推年度节省。不同载能 kWh 不无解释相加为医疗损害。未通过、回退、未知尾段和未启动槽均保留在本轮实测账中。
