# V27 假设与用途限制

本表补充、保留旧V26假设；旧28输入、旧故障/服务阈值与失败结论不改。

| 项目 | 本轮约定与限制 |
|---|---|
| 模型 | 共同M25物理执行核心，新V27策略/来源研究身份。给定聚合需求的电热冷供能工程代理，不是实测全院数字孪生。 |
| 目标 | 服务与已登记准备/备用/调节一致性先，原货币目标后，再择优在线台数/连续性。regulator与第三台暴露均是软偏好，收益/可靠性不作为硬保证。 |
| 旧路由 | 缺省及显式legacy_before_cost保留，after_cost独立命名。legacy_C19_order指准备/备用群排序，不能解释为新台数仍在费用前。 |
| 启动 | 原10min GT启动、10kW/台启动电及原最短开停/重置/接触器规则保留。命令/许可/待启动/实际出力分开；同刻旧停止可取消尚未付款的启动。无OEM磨损/固定费/故障概率补值。 |
| 费用 | 原USD2001价格、燃料转换、分时价函数不改。计划向量含旧弱偏好和DG代理；纯实际费用使用原生电/气/DG轴功，弱偏好单列，既有energy_cost别名不能当纯实际费。 |
| 末态 | 90–180分叉能源库存相同但GT冷热状态不同，不给影子价或长期等终态收益。14h比较沿同末端规则，也不证明全时域最优。 |
| 冷需求 | 原年度八盘管TOTAL W/1000，不能用蒸发产冷重复加需求；关键区显冷是代理，不是全部临床负荷实测。各字段倍率按其定义只算一次。 |
| 年度来源 | 找回真实26.2派生IDF/SQL/脚本，四CSV实际重提取byte-identical。SQL只存Hourly，无年度真实substep可还原；完成flag FALSE与结束成功/0severe矛盾未解；22,832,532次警告保留。 |
| 时钟 | 分标准时/报告夏令时和小时末标签。2017 SQL与2006报告标签相关月日weekday对应，未因年份不同判错；有限7月RunPeriod与全年热历史不等价。 |
| 条件输入 | 原年度基线+完整有符号120h原/Min8正常差，14区逐区显冷变化后原倍率/分级；独立版本3新输入，不替换原28、不把Min8当真值。负需求/代理超总拒绝，未扩大授权小时。 |
| 初态与信息 | 同原输入/seed先reset，t0才启用条件当前需求；合法pre0历史不改。非扰动后再平衡预热态，控制器只接当时记录；不提供环境隐藏故障计划、真实修复时刻或未来需求。 |
| 非冷边界 | 外生聚合E/H/reference相同，但原聚合电需求内辅机重分配导致建筑aux+15.349983kWh、direct分解等量减少。逐台直接临床负荷固定命题未证为U；条件S仅适用原聚合边界。 |
| 冷侧资格 | V26三环全控制体残差与min8诊断仍不合格，水量为模型自动估算非实测。停源后盘管冷量不入IES备用。未新增EP或扫描迭代。 |
| 温度资格 | 两候选已有限失败并退役独立验收用途，仍0/8，不fit/新增热容/外推；默认None，公开请求未合格用途会拒绝。 |
| 排放 | 原登记CAMX/燃气/DG条件因子，不为调度目标或生命周期实测。实际能源费下降可以伴随条件CO₂上升。 |
| 存储 | H0 UPS/蓄冷容量0是absent，非0min耗尽；DG2400kWh未用不证明事故耐久。各载能库存/燃料及实际扣款保留原定义。 |
| 候选拒绝 | 不可行探针、原域拒绝与后续严格校验接受逐次记录；完成程序不等于每个候选均最优。原单位/归一化锁容差不放宽。 |
| 导出 | V26四个*_W阶段总量另导出为*_kWh，原值不变。数学无限边界显式标签，不置0。A1顶层policy_id是续跑上下文，前0–90行为仍legacy；只用于离线工程复核，不混作全程新策略训练样本。 |
| 重放健壮性 | 当前原生时钟另有SQL/API严格核对；load_replay年度8coil算术以行序对照，未再次独立比较timestamp索引，属将来更换证据前应补强项，不把本次可重复等于任意新文件均正确。 |
| 交付 | 必要原生数据与完整采用快照入包；大SQL、深层矩阵及完全相同/被替代副本本机保留并逐件SHA登记。全矩阵级复核需所列原件或按公开入口重跑，不冒充整个旧研究档案。 |

具体下一步：若要超出条件S，先建立有独立直接用电和辅机基准的计量边界，再验证新增冷需求是否增加总电需求；年度物理准确性、动态冷水与温度用途另需独立资格，不能用本轮代码测试或有限费用优势补证。
