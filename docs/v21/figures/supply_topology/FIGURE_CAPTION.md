# 医院供能与服务依赖关系图

图示 M21 中已建模的能源转换与必要辅助依赖。关键建筑电负荷包括从原全院用电重新归属的必要风机与输配辅助电；EC/ABS 的原辅机系数与另行登记的输配泵分开，避免重复计电。共享散热路径、冷冻水输配和空气侧服务分别构成制冷交付条件。有限 UPS 与有限蓄冷为 H1、H2 独立硬件配置，不能据图理解为 H0 已有设备。

区域名称用于说明源数据追溯及聚合权重。实际供能核算为 P0–P3 × 电/热/冷的四乘三矩阵；不能解析同一等级内 OR、ER、ICU 等房间各自的交付，命名区域风机故障也按其源贡献权重作用于等级服务能力。箭头不是已核实的医院实际馈线、水力管网或独立房间回路，风机有电亦不证明换气、压差或感染控制达标。

图中供能资格不等于设备已经就绪、命令已经到达或能源已经实际交付。供能接续、备用扣账及恢复时刻以对应真实过程图、事件表和 RESULT 为准。可识别的 P3 生活热水允许保留有来源的非空气侧热量上界，仍受热源和供热泵约束；它不是单独的实际 DHW 交付计量。
