# V22 医院供能模型验证报告

状态：本轮模型实现与针对性开发/回归验证完成；温度定量精度未通过，条件及缺证按下文保留。所有表来自实际记录，非历史数字倒填。

## 实际供能过程与仍然存在的中断

本轮修正的是同一医院模型的实际供能关系。建筑电端、输配泵及区域风机、能源站锅炉/GT启动、DG专用启动DC各有明确边界。库存不是一个可以跳过设备路径的通用电源；设备状态ready也不代替实际供电或已完成启动。共同模型使用同一个电/热/冷平衡，电源与冷/热端必须同时支持必要辅机。

UPS仍为原40kWh/160kW，只接建筑侧。当前关键电需求和已知启动/切换时钟形成库存目标；当前关键缺口可继续使用库存。DG已经能满足当前供给时，实际UPS放电先最小化，再用真正余源回充，避免为省燃料把再次桥接库存耗空，也避免正常段反复充放。短复发例中，GRID在75.5min实连，UPS在82.346672min回满；90min再次真实切断GRID，UPS桥接第二次DG的10s启动，输出0.239136858kWh，库存40→39.748276992kWh。GT在第二次扰动前没有供电，因此不把该例描述为第二次GT实际掉电。

这里“DG足够”指当前已到达许可及实际源/辅机约束下足够，不仅是CONNECTED或900kW铭牌。当前策略仍可能发出偏低DG许可，UPS为当前关键服务补电；不能硬禁这类必要放电。90min原启动延迟例在观察末尾仍未实际并回GRID，UPS末库存约11.525kWh，并不承诺停电后仍满库或任意长桥接。保留库存与DG备用/一般服务之间仍有真实运行取舍。

建筑UPS不接能源站AC，不能支付锅炉或GT启动电，也不补DG专用启动资格。冬季复合故障中，H1将P0/P1材料性电中断从15.25min降至0min（每组原始微量ENS约0.00017068kWh仍保留），而热仍断17.25min、冷仍断15.25min。旧模型中看似随UPS一起消失的热中断不能继续作为物理收益。能源站恢复后，锅炉还需连续支付1min复归电；这是显式研究时钟，不能解释为真实冷态锅炉升压时间。

原60kWh/120kW蓄冷在健康GRID、部分塔降额时可放冷，但必须有实际泵电、风机和冷水路径。TOWER剩1%案例中，自事故15min起支持约42.936min，57.9355min首次耗空，随后仍有关键冷缺口；事故75min结束后实际回充，终点库存没有被当作免费经济收益。无泵、无风机时，即使有库存也不虚构交付。

原EC-only案例保留ABS后关键冷服务完整、蓄冷未放冷；原reset空库存案例在事故前15min确实充入了冷量。这两个真实结果分别说明替代冷源和提前回充的作用，不证明其文件名暗示的边界。额外登记的t=0冷机全退出满库/空库对照，用于在同一真实事故起点核查库存边界，不改变原42例。

067的提前失供来自上层当前许可被整步能量限制，并非执行层尚有库存就一定能补足。原375min许可约63.00348kW、库存15.75087kWh，P1已缺电；新当前许可按实际瞬时能力编译，允许原执行层细分到真正耗尽。但站电也有真实消耗：新模型380.683072min耗尽，早于旧386.666672min。局部提前缺口被修正，总保障时间没有因此延长；P0/P1各载能ENS及恢复时间须同时报告，不能把低费用写成优势。

单独站AC在90–120min中断时，DG已于75min供电，建筑UPS仍能支持建筑电，却不能绕开断开的站支路；关键并集失供合计48.25min。DG专用启动DC从0至120min不可用的例子中，GRID/GT从60min退出后，只有有限UPS桥接，DG要到120min资格恢复、135min完成原15min启动才实际供电，关键并集失供77.25min。这两例恢复后的实际GRID回接均为210.5min，不能把180min硬件修复当作已并回电网。

## 温度：修正执行完成，定量验收失败

采用真实净显热ΔH−ΔC和连续1R1C状态，恢复不清零；主动恢复按实际额外冷量扣热库存，被动散热另按热平衡独立闭账。当前完整加热仅Hourly，不伪造10min输入。一次两参数有界fit、12次函数评价，四种方法×四个已见日期16行均未同时达到预登记目标；拟合参数不部署，未增加热状态或重复拟合寻找通过。

公平的8/15同Hourly比较：事件RMSE3.384158→1.860554℃、恢复6h RMSE4.275557→1.815889℃、最大误差6.375107→2.465742℃、首次研究越限误差100→40min；恢复时间仍未确定。目标分别为1/.5/2℃、10/20min，完整输入间隔≤10min；实际60min本身不满足时间目标。以上改善不能抵销冷ENS，也不能作为关键控制或临床温度保障依据。
