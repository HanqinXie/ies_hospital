## 修正后的冻结含义

普通源建筑实际交付 = 建筑总交付 − 各专用源实际交付。普通电源归一化分母包含它实际负担的机房与充电端口；普通冷源分母包含原有冷充电端口。专用源不再次进入普通源分母。原始普通端口、分母、各专用源交付和推导依据均保存。

每个源组的权重冻结一次；故障、容量、需求封顶和库存事件可降低交付，未用额度不转供，零份额不重新开启。UPS、柴油、蓄冷保留原 P0/P1 连接，不扩展至 P2/P3 或机房；活跃源使用自己的实际分流，未工作的备用继续使用原已登记的关键支路服务比例作为待命代理。该待命比例是模拟假设，不是实测流量，也不等于增加新的自动启动权限。

来源身份采用机器舍入量级核对，不把物理能量容差当成允许重构支路的误差。允许的舍入差额在归一化前规范为零，记录 `source_roundoff_bound_kW` 与 `ordinary_roundoff_removed_kW`；不可把极小残差归一化成新支路。零总量源的非零显式交付拒绝。物理账本和库存验收仍沿原容差，不为通过测试扩大容差。

## 原有自动响应和旧命令

- 按缺口启动/放电仅沿既有备用连接、固定组内比例、功率/库存/泵电与事件约束执行，无 P0→P3 排序。
- 电网余缺平衡仅适用于原登记的 `arrived_ceiling` 合同；非此合同显式拒绝，不能擅自把固定进口合同变成可调上限。
- 锅炉仅在原目标以下、固定支路与实际蒸汽用途约束内求闭合；该当地调节仍是已登记聚合代理，无现场动态资格结论。
- 检查点正在重启且有已到达旧锅炉目标时，保留该目标及原时钟；不能因瞬时出力为零把它永久锁成零。
- 旧命令携带实际计划时可按原到达时间更新设备参考。只有许可上限、没有实际计划时，许可照常到达，但不能据上限生成新的运行参考。
