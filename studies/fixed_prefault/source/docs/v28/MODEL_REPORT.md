# V28 医院能源与服务边界修正结果

本轮把“医院提出多少直接用电与热冷服务请求”和“风机、水泵实际消耗多少电、最终交付多少服务”分开。修正后的主实验共11条，均完成原生过程记录与独立算术核验；没有修改容量、故障幅度、原保护/失效阈值、价格或关键服务分组，没有引入MPC或未来故障信息。研究使用给定原型医院及已见背景，不能作为真实医院或跨背景可靠性认证。

## 医院供能和接续结果

### 电边界修正：新增冷服务不再挤掉直接电请求

A阶段保留原热输入，比较标准时7月20日04–18时同初态的C/M两种既有运行方式、原冷与条件冷四例。源模型分解的非辅机直接电请求固定，不是逐台临床实测；条件冷使建筑辅机请求增加15.3499828344kWh，实际额外购电还包括原有冷站转换电。不能把这一需求变化写成同量失供。
