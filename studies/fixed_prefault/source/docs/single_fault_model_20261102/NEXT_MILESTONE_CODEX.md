## 八项必须处理
1. T01：真实GT电/余热/辅助电/燃料或其等价预算边界；健康热源合法承接；退出、修复、重启状态及分段一致性。
2. T02：健康GT背景下查原合法正常供汽窗口；独立锅炉故障的正暴露、容量/耗能/站用电/许可/恢复。三份额仍为聚合；若全支持搜索无正暴露，完成部件验证并明确系统独立验证未覆盖，不以GT先坏替代。
3. T03：ABS冷量/发生器吸热/排热/辅耗同步；释放蒸汽去向；EC/储冷经原支撑与队列；准入限制与物理可行性分开。
4. T04：以EC单台故障为主，压缩功/冷量/辅助电/排热边界、all-in重复计量检查及合法替代，硬件和执行许可分列。
5. T05：塔吨位/容量/数量/回路来源，单对象/共因对象定义，共享排热不重复分配/降额；有资料才升级性能，代理.01不得实体化。
6. T06：原IDF/SQL的泵/管网/储冷/负荷连接与辅耗；实际输送/库存一致，不编旁路/泵曲线；有来源才升级水力。
7. T07：仅一次网侧故障，实际母线供电、UPS/DG/GT启动、ATS/回切，电能/启动资格/轴功预算分列，无越拓扑/无电启动/免费资源恢复。
8. T08：同次单故障后的自然恢复；功率/效率/站损/切换及分段一致性；实际能源补库、温度恢复和热债；各恢复时钟/删失分开，无第二事故/状态重置/无依据安全阈值。
